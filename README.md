# Коментар Закона о арбитражи

Коментар српског прописа: **Закон о арбитражи** („Службени гласник РС“, број 46/2006). Обухвата **70 јединица** – чланове 1–70 закона – у 3 поглавља коментара; уз сваки члан дат је дословни текст одредбе и коментар.

Стање прописа према: редакцијски пречишћен текст Правно-информационог система Републике Србије, у коме је као једина објава наведен „Службени гласник РС“, број 46/2006 (закон према том извору није мењан); текст преузет 2. октобра 2026.

## Садржај

Види [INDEX.md](INDEX.md). Опис метода у [00-uvod.md](00-uvod.md).

1. Основне одредбе, споразум о арбитражи, арбитражни суд (гл. I–III, чл. 1–18)
2. Арбитри, надлежност арбитражног суда, поступак пред арбитражним судом (гл. IV–VI, чл. 19–47)
3. Арбитражна одлука, поништај, признање и извршење, завршне одредбе (гл. VII–X, чл. 48–70)
